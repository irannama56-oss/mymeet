# 2026-10-07

## UI review & fixes (mymeet / Aura Meet)

User asked to review and fix all UI issues. Measured-first audit using puppeteer-core at widths
320/360/390/414/480/600/640/700/768/820/900/1024/1100/1280/1440/1920. No `hScroll` anywhere; the only
"overflow" flags were decorative blur blobs (clipped by parent). Focused on real bugs.

### Fixed

1. **`Lobby.tsx` — tab buttons (`New Meeting` / `Join with Code`)**
   - Added `min-w-0 truncate` so flex-1 items can actually shrink below min-content
   - Smaller text on narrow widths (`text-[11px] sm:text-xs`)
   - Added gap-1 between tabs
2. **`Lobby.tsx` — Mic/Camera `<select>` elements**
   - `truncate` does nothing on native `<select>` — replaced with custom chevron + `appearance-none pr-4` + `style={{ textOverflow: 'ellipsis' }}`
3. **`Lobby.tsx` — header**
   - Removed dead `max-w-6xl mx-auto` (had no effect with absolute left/right). Tighter padding at narrow widths (`top-4 sm:top-6`).
4. **`VideoTile.tsx` — Hand raised + Screen share badges overlap**
   - Both were `absolute top-3.5 left-3.5` — would stack on top of each other when both true
   - Now wrapped in a vertical flex column (`absolute top-3 left-3 flex flex-col gap-1.5`)
   - Long label "X's Screen" gets abbreviated on mobile (`<sm` shows just "Screen")
5. **`VideoTile.tsx` — duplicate `object-contain` in className** (dead code)
   - className had `object-contain` as default, then `object-cover` overrode in the local branch
6. **`VideoTile.tsx` — duplicate audio play()**
   - Both `autoPlay` on the `<audio>` and a useEffect calling `el.play()` — kept one, with trackCount dep so re-runs on stream swap. Also removed unused `attachVideo` callback.
7. **`VideoTile.tsx` — removed unused imports** (`Shield`, `useCallback` re-added since it's still used by `attachAudio`)
8. **`ParticipantsDrawer.tsx` — participant row overflow**
   - Added `min-w-0 flex-1` to left side, `min-w-0` on the name (was `max-w-[120px]`), so name truncates instead of pushing icons off-screen
   - Added `gap-2` between left and right clusters
9. **`ParticipantsDrawer.tsx` — knock request rows**
   - Same `min-w-0 flex-1` fix; gap-2 between clusters
10. **`ParticipantsDrawer.tsx` — header**
    - Same shrink-0 / min-w-0 / truncate fix so title + close button don't crowd on narrow widths
11. **`ParticipantsDrawer.tsx` — removed unused imports** (`VolumeX`, `Shield`)
12. **`ChatDrawer.tsx` — header** (same defensive pattern as ParticipantsDrawer)
13. **`SettingsModal.tsx` — Screen share quality grid**
    - Was `grid-cols-3 gap-2` at all widths (3 columns of 90px at 320px — cramped)
    - Now `grid-cols-1 sm:grid-cols-3` — stacks on mobile
    - Header label truncated Persian parenthetical that mixed scripts on small screens
14. **`SettingsModal.tsx` — Screen Share Quality header row**
    - Same shrink/min-w-0 fix so the right-side badge doesn't push the label off
15. **`MeetingHeader.tsx`**
    - Tighter padding on mobile (`top-3 sm:top-4`, `left-3 sm:left-4`, `right-3 sm:right-4`)
    - Room code uses `truncate min-w-0` with `max-w-[60vw]` so it ellipsis instead of pushing buttons off
    - `Invite` text hidden under `sm` (just shows the icon at narrow widths)
16. **`MeetingControls.tsx` — reactions popover**
    - Was hard-coded width — now `max-w-[92vw] overflow-x-auto` so it can't push off-screen
17. **`KnockModal.tsx` (HostKnockBanner)** — On narrow widths the centered max-w-md banner was wider than viewport with internal content overflow
    - Switched to `left-3 right-3` on mobile (full-bleed with small margin), centered max-w-md from `sm` up
    - Tightened avatar/button sizes on mobile
18. **`ConnectionBanner.tsx`** — When Supabase IS configured and status is still `'connecting'`, the banner was returning null (gap). Added 'connecting' and 'disabled' states so users always see what's happening.

### Verified

- `tsc --noEmit` clean
- `npm run build` succeeds (1648 modules, 45 kB CSS, 129 kB JS)
- `hScroll: false` on all 16 swept widths; the only "overflow" flags were the 3 decorative glow blobs (`top-1/4 left-1/4`, `bottom-1/4 right-1/4`, `top-1/2 right-1/3`) clipped by parent `overflow-x-hidden`
